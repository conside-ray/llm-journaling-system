# Privacy

Journal content can contain highly sensitive personal information.

## Recommended usage

- Create a private repository from this template.
- Do not store real journal content in a public fork.
- Review all staged files before committing.
- Understand whether your chosen AI model processes data locally or sends
  selected content to a remote provider.
- Do not commit API keys, credentials, client information or private
  conversations.

## Important

This public repository contains synthetic examples only.

Deleting sensitive files from a working tree does not necessarily remove
them from Git history. Never publish an existing private journaling
repository by simply deleting personal files.
